# Cursor Mover

macOS 多显示器效率工具：快捷键切换鼠标所在显示器、移动窗口和切换窗口大小。

- [官方网站](https://ityuany.github.io/cursor-mover-website/)
- [下载应用](https://github.com/ityuany/cursor-mover-website/releases)
- [反馈问题](https://github.com/ityuany/cursor-mover-website/issues)

支持 macOS 13.5 及以上，兼容 Apple Silicon 和 Intel Mac。
下载 ZIP 后解压，将 CursorMover.app 放入应用程序文件夹，启动后授予辅助功能权限。

本仓库用于官网部署、应用分发与用户反馈，不包含应用源码。
官网文件由开发仓库自动同步；应用在开发仓库完成构建、签名和 Apple 公证后上传至本仓库的 Releases。

Release 中的 `CursorMover-版本.app.zip` 是安装包，`.sha256` 文件用于校验。
GitHub 自动提供的 Source code 压缩包仅包含本网站仓库的文件，不是应用源码或安装包。
