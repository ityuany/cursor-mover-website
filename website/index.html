LESS MOVEMENT. MORE MOMENTUM.

少一点操作，多一点专注。

三个恰到好处的功能，照顾你的每一块屏幕。

↗01 / CURSOR

鼠标，一键跨屏。

按下快捷键，鼠标即刻来到下一块显示器的中心。不用来回拖动，也不必在桌面上寻找光标。

放大或光晕，让落点更清楚
▣02 / WINDOW

窗口，跟着思路走。

将当前聚焦窗口移到下一块屏幕，保持原有大小并居中。鼠标随之移动，接着完成手上的事。

单屏使用，也能一键居中
⤢03 / FOCUS

舒展一下，再回原位。

把窗口按偏好比例居中缩放，再按一次，恢复原来的位置与大小。在专注和全局之间自如切换。

60%–95% 可调窗口比例
